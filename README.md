# methbam-taiwan

แผนเที่ยวไต้หวัน 16–20 ธ.ค. 2569 — เว็บหน้าเดียวสร้างด้วย Vite 5 แท็บ: แผน (รายวัน) · แผนที่ · สถานที่ · งบ · เตรียมตัว

เปิดดู: https://methxmaster.github.io/methbam-taiwan/ (หน้า `index.html` ที่รากจะ redirect ไป `docs/`)

## พัฒนา

```bash
npm install
npm run dev      # เปิดเซิร์ฟเวอร์พัฒนา
npm run build    # สร้างเว็บเข้า docs/ (ต้อง commit ผลลัพธ์ด้วย)
```

- โค้ดอยู่ใน `web/` (ข้อมูลทริปอยู่ที่ `web/src/trip.json`, รายการเตรียมตัวที่ `web/src/todo.js`, รูปสถานที่ใน `web/public/img/`)
- ผลลัพธ์ build อยู่ใน `docs/` ซึ่ง GitHub Pages เสิร์ฟ ถ้าตั้ง Pages เป็น `main` + `/docs` ได้โดยตรง ไม่ต้องผ่าน redirect

## หมายเหตุ

- เวลาเดินทาง ชั่วโมงเที่ยว และราคาส่วนใหญ่เป็นค่าประมาณ ยังไม่ได้เช็คกับแหล่งจริง
- ตัวเลขในแท็บงบแก้ได้ในหน้าเว็บ ค่าที่แก้และการติ๊กรายการเตรียมตัวจำไว้เฉพาะเบราว์เซอร์ของคนที่แก้
- ไม่เก็บข้อมูลส่วนตัว (รหัสจอง ชื่อ พาสปอร์ต) ในรีโป
